DFA Input String Acceptance Checker

AL102 — Automata Theory. Deterministic finite automaton accepting exactly the string 101.

Diagrams are inline SVG; draw.io source for each is included and can be exported with the buttons below.

1. Formal definition

States
Q = {q0, q1, q2, q3, qd}
Alphabet
Σ = {0, 1}
Start state
q0
Accepting state
F = {q3}
Dead state
qd
Transition function
δ : Q × Σ → Q
Language
L(M) = { 101 }

The machine reads one symbol at a time from left to right. It accepts only when the entire input equals 101. Any deviation sends the machine to qd, from which no symbol can return it.

Three consequences worth stating explicitly, because each is easy to get wrong:

  • 1010 and 1011 are rejected. q3 has no self-loop, so any fourth symbol traps the machine. This is what makes the language the single string 101 rather than "strings beginning with 101".
  • 1101 is rejected even though it ends with the same three characters. The automaton is anchored at the start of the input and falls into qd on the second symbol.
  • The empty string is rejected: zero transitions are taken, the machine stays in q0, and q0 is not accepting.
